# Template, specification and license provenance

AIC uses the self-contained `skills/<name>/SKILL.md` layout and progressive-disclosure pattern demonstrated by Anthropic's official skills repository and the Agent Skills standard. The metadata-only basic template is a structural reference, not a claim that every file in the upstream repository has one license.

## Research and memory references

The portable [research evidence and rights ledger](research.md) records primary-source authors/research teams, publication dates and exact versions, evidence tiers, applicability limits, license evidence and checked dates. It covers the workflow sources and the existing references in [memory.md](memory.md): the Dartmouth/Microsoft/independent-researcher conversational-memory study, Anthropic's context-engineering and containment articles, and OpenAI's memory/compaction example.

All such research sources are **citation/reference-only in AIC**. No upstream paper PDFs, text excerpts, figures, tables, prompts, datasets or research implementation code are vendored. Original summaries discuss findings without reproducing upstream expression. Unknown or restrictive publication licenses are not treated as permissive because a page is publicly readable or a preprint is on arXiv.

The Google collaboration article in Nature Machine Intelligence is CC BY-NC-ND 4.0; the separate Nature Co-Scientist journal article is CC BY 4.0. CAID's current COLM conference PDF and BOAD's ICLR conference PDF have unverified publication-reuse grants, regardless of their differently licensed preprints. Evolving Agent Teams' specified preprint uses arXiv's non-exclusive distribution license. Other specified preprints and the ACL memory paper have verified CC BY 4.0 evidence. EAT implementation code is Apache-2.0; BOAD's LICENSE and pinned OpenAI Cookbook/DeepSeek Harness source are MIT. CAID metadata declares MIT but a complete standalone notice was not verified. The tmux 3.8 COPYING is ISC-style; AIC distributes only its own original optional profile, not tmux. None of these source-code grants establishes rights in an associated paper, website or every dependency. See the ledger for exact versions and unresolved permissions; no cited material is relicensed by AIC.

Engineering guidance, product documentation and experimental benchmark findings are different evidence types; none establishes a universal best current model or grants operational authority. Product documentation establishes reported capability, not comparative quality. Stars, downloads, agreement and model confidence are not verification.

Keep this file, the research ledger, LICENSE/installed LICENSE.txt and NOTICE with portable distributions. Future copying or source updates require a separate rights review for the actual material/version and preservation of its required notices; these references are not a blanket reuse authorization.
